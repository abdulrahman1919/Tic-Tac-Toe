## 🎯 How to Play

1. Click **Start Game**.
2. The first player places **O**.
3. The second player places **X**.
4. Players take turns selecting empty cells.
5. Get three matching symbols in a row, column or diagonal to win.
6. Use **New Game** or **Reset** to play again.
